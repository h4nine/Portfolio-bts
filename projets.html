API Pour BDD

A FastAPI-based translation management system with: Multi-language support User management Translation sessions Validation workflow Session stats Installation 1. Install Dependencies pip install -r requirements.txt 2. Run the API source venv/bin/activate # if using a virtual environment python3 main.py The API runs at: http://localhost:8000 API Documentation Replace localhost with the ip address of the virtual machine !! Interactive documentation available at: http://localhost:8000/docs API Endpoints Users (/users) Method Endpoint Description POST /users/ Create new user GET /users/{user_id} Get user by ID GET /users/ List all users PUT /users/{user_id} Update user DELETE /users/{user_id} Delete user (soft) Languages (/languages) Method Endpoint Description POST /languages/ Create new language GET /languages/{code_language} Get language by code GET /languages/ List all languages PUT /languages/{code_language} Update language Medical Sentences (/medical_sentences) Method Endpoint Description POST /medical_sentences/ Create new sentence GET /medical_sentences/{sentence_id} Get sentence by ID GET /medical_sentences/ List sentences (with filters) PUT /medical_sentences/{sentence_id} Update sentence POST /medical_sentences/{sentence_id}/validate Validate sentence Query Filters skip, limit — Pagination code_language — Filter by language creator_id — Filter by creator validated_only — Show only validated sentences Translations (/translations) Method Endpoint Description POST /translations/ Create new translation GET /translations/{translation_id} Get translation by ID GET /translations/ List translations (with filters) PUT /translations/{translation_id} Update translation POST /translations/{translation_id}/validate Validate translation Query Filters skip, limit — Pagination sentence_id — Filter by sentence session_id — Filter by session translator_id — Filter by translator validated_only — Show only validated translations Sessions (/sessions) Method Endpoint Description POST /sessions/ Create new session GET /sessions/{session_id} Get session by ID GET /sessions/ List sessions (with filters) PUT /sessions/{session_id} Update session POST /sessions/{session_id}/end End session GET /sessions/{session_id}/statistics Get session stats POST /sessions/{session_id}/update-progress Update progress Query Filters skip, limit — Pagination creator_id — Filter by creator status — Filter by status (started, finished, quit) active_only — Show only active sessions Example Usage Get all languages curl http://localhost:8000/languages/ Get specific language curl http://localhost:8000/languages/ar List medical sentences (paginated) curl "http://localhost:8000/medical_sentences/?skip=0&limit=10&validated_only=true" Get session statistics curl http://localhost:8000/sessions/ses_123/statistics Validate translation with score curl -X POST "http://localhost:8000/translations/tra_123/validate?score=95.5" Project Structure db-validator/ ├──
